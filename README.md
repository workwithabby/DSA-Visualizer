# Data Structures & Algorithms Visualizer

An interactive Next.js learning tool for exploring data structures and algorithms through explanations, visualizations, and step-by-step playback.

## Features

- Interactive data structure visualizations
- Algorithm playback with step controls
- Searching and sorting demonstrations
- Complexity notes and code examples
- Light and dark themes

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

### Requirements

- Node.js 20 or newer
- npm

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Create a production build
- `npm run start` - Start the production server
- `npm run lint` - Check the code with ESLint

## Deployment

The website is deployed on [Vercel](https://vercel.com).
